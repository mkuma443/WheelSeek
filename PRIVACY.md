# WheelSeek Privacy Policy

Last updated: July 27, 2026

WheelSeek does not collect, sell, share, or transmit personal information,
browsing history, viewing history, authentication information, or website
content.

WheelSeek runs locally in the browser on supported YouTube and Twitch pages. It
reads the active video element, its seekable time range, and broadcast metadata
already present on the current page solely to provide seeking and the optional
broadcast-clock display.

The extension stores these user preferences with Chrome's `storage.sync` API:

- Default seek duration
- Whether variable seek is enabled
- Whether the broadcast clock is enabled

Chrome may synchronize these settings between browsers signed into the same
Google account according to the user's Chrome synchronization settings.
WheelSeek's developer does not receive them.

WheelSeek does not use analytics, advertising, remote code, or third-party
tracking services.

Questions about this policy can be directed to the support contact shown on the
WheelSeek Chrome Web Store listing.
