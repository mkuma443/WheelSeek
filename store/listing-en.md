# Chrome Web Store listing copy (English)

## Product name

WheelSeek

## Summary

Seek YouTube and Twitch videos with the mouse wheel, with variable jumps and an experimental broadcast-time overlay.

## Category

Productivity

## Detailed description

WheelSeek lets you seek YouTube and Twitch videos quickly with the mouse wheel.

It activates only while the pointer is inside the rendered video area, so the
page scrolls normally everywhere else.

Core features:

• Wheel up to seek forward  
• Wheel down to seek backward  
• Choose a default seek amount from 5 to 30 seconds  
• Hold Shift for a fixed 30-second seek  
• Supports regular videos, seekable live streams, and live archives  

Experimental features:

• Variable seeking from 5 to 60 seconds based on wheel intensity  
• Estimated original broadcast time while seeking live streams and archives  

The broadcast-time overlay is designed for comparing multiple streamer
viewpoints from the same livestream event at approximately the same time. If a
reliable start timestamp is unavailable for an archive, WheelSeek does not
guess and displays only the seek amount.

Currently excluded:

• YouTube Shorts  
• Twitch Clips  
• Players embedded on third-party websites  

Privacy:

To provide its features, WheelSeek temporarily processes video information,
seekable ranges, live-start metadata, wheel input, and pointer position on
supported pages. This processing occurs on the user's device. The information
is not collected, retained, transmitted, or shared with third parties.

Only the default seek duration and experimental-feature preferences are stored
with Chrome Sync. WheelSeek uses no analytics, advertising, tracking services,
or remotely hosted code.
