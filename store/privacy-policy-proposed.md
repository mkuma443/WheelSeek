# WheelSeek Privacy Policy / プライバシーポリシー

Last updated / 最終更新日: July 27, 2026 / 2026年7月27日

## 日本語

WheelSeekは、YouTubeとTwitchのシーク可能な動画をマウスホイールで操作する
Chrome拡張機能です。

### 端末内で処理する情報

WheelSeekは、機能を提供するために、対応ページ上で次の情報を端末内処理します。

- 動画要素と現在の再生位置
- プレイヤーのシーク可能範囲
- ページ内に既に存在するライブまたはVODの開始日時メタデータ
- ホイール入力の方向と量
- ポインターが動画領域内にあるかを判定するための位置

これらの情報は機能の実行中に一時的に処理されるだけです。WheelSeekの開発者が
収集、受信、閲覧することはなく、外部サーバーへの送信、永続保存、販売、
第三者共有も行いません。

### 保存する設定

WheelSeekは、Chromeの`storage.sync` APIを使用して次の設定を保存します。

- 通常のシーク秒数
- 可変シークのON／OFF
- 放送時刻表示のON／OFF

Chrome Syncが有効な場合、GoogleはユーザーのChrome同期設定に従って、
これらの設定を同じGoogleアカウントでログインしているブラウザ間で同期する
ことがあります。WheelSeekの開発者がこれらの設定を受信することはありません。

### データの共有と第三者サービス

WheelSeekは、分析、広告、トラッキングサービスを使用しません。ユーザーデータを
販売または第三者へ共有せず、外部でホストされたコードも実行しません。

### Limited Use

WheelSeekによるユーザーデータの利用は、Chromeウェブストアのユーザーデータ
ポリシー（Limited Use要件を含む）に準拠します。対応ページのコンテンツおよび
ユーザー操作は、ユーザー向けシーク機能の提供に必要な範囲で端末内処理する
ためだけに使用します。

### 設定の削除

保存された設定の同期と削除は、ユーザーのChrome Sync設定およびChromeによる
拡張機能データの管理に従います。

### お問い合わせ

質問や不具合報告は、WheelSeekのGitHub Issuesへお願いします。

https://github.com/mkuma443/WheelSeek/issues

## English

WheelSeek is a Chrome extension that lets users seek supported YouTube and
Twitch videos with the mouse wheel.

### Information processed locally

To provide its features, WheelSeek processes the following information locally
on supported pages:

- The video element and current playback position
- The player's seekable time range
- Live or VOD start-time metadata already present on the page
- Wheel-input direction and intensity
- Pointer position used to determine whether the pointer is inside the video

This information is processed temporarily only while providing the feature. It
is not collected, received, or viewed by the WheelSeek developer. It is not
transmitted to external servers, retained, sold, or shared with third parties.

### Stored preferences

WheelSeek uses Chrome's `storage.sync` API to store:

- Default seek duration
- Variable-seek enabled state
- Broadcast-clock enabled state

When Chrome Sync is enabled, Google may synchronize these preferences between
browsers signed into the same Google account according to the user's Chrome
sync settings. The WheelSeek developer does not receive these preferences.

### Data sharing and third-party services

WheelSeek uses no analytics, advertising, or tracking services. It does not
sell or share user data and does not execute remotely hosted code.

### Limited Use

WheelSeek's use of information complies with the Chrome Web Store User Data
Policy, including the Limited Use requirements. Supported page content and
user interactions are processed locally only as necessary to provide the
user-facing seek functionality.

### Deleting preferences

Synchronization and deletion of stored preferences are governed by the user's
Chrome Sync settings and Chrome's management of extension data.
